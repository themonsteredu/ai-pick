# AI 선택 훈련소

중학생 대상 AI 리터러시 수업용 웹앱입니다. (90분 = 45분 × 2차시, 한 반 20~30명)

> **핵심 메시지**
> 가장 비싼 AI를 쓰는 사람이 AI를 잘 쓰는 게 아니다.
> **문제에 맞는 도구를 고르고, 좋은 질문을 만들고, 답을 검증하는 사람**이 잘 쓰는 사람이다.

---

## 처음 실행하는 법 (내 컴퓨터에서 확인하기)

터미널에서 이 폴더로 이동한 뒤, 아래 두 줄을 차례로 칩니다.

```bash
npm install
npm run dev
```

그리고 웹 브라우저에서 아래 주소를 엽니다.

```
http://localhost:3000
```

> Supabase 설정을 아직 안 해도 그냥 돌아갑니다. (임시 저장 모드)
> 다만 서버를 껐다 켜면 만들었던 수업코드가 사라집니다.

## 4단계 (앱 안에서 쓰는 유일한 표현)

| 표시명 | 크레딧 | 언제 쓰나 |
|---|---|---|
| 사람 · 직접 | 0 | AI에게 맡기면 안 되는 일 |
| 빠른 AI | 1 | 단어 뜻, 제목 추천, 아이디어 |
| 생각하는 AI | 2 | 글 수정, 조건 반영, 비교 설명 |
| 깊게 파는 AI | 4 | 긴 자료 분석, 오류 찾기, 근거 판단 |

**이 앱에는 특정 AI 회사 이름·모델명·요금제가 어디에도 나오지 않습니다.**

## 글꼴 — 에스코어드림

제목과 본문 모두 **에스코어드림(S-Core Dream)** 을 씁니다. (무료 사용 가능 글꼴)

굵기는 3종만 불러옵니다. 인터넷에서 자동으로 받아오므로 따로 설치할 게 없습니다.

| 쓰이는 곳 | 굵기 |
|---|---|
| 본문 | Regular |
| 버튼 · 소제목 | Bold |
| 큰 제목 · 수업코드 | Black (아주 굵게) |

### 만약 학교 인터넷이 글꼴을 막는다면

교실에서 글자가 기본 글꼴로 보인다면, 글꼴 파일을 우리 서버에 직접 넣으면 됩니다.

1. `https://github.com/fonts-archive/S-CoreDream` 에서
   `SCDreamRegular.woff2`, `SCDreamBold.woff2`, `SCDreamBlack.woff2` 3개를 내려받습니다.
2. `public/fonts/` 폴더를 만들고 그 안에 넣습니다.
3. `app/globals.css` 맨 위의 주소 3곳에서
   `https://cdn.jsdelivr.net/gh/fonts-archive/S-CoreDream/` 부분을 `/fonts/` 로 바꿉니다.

## Supabase 연결하기 (실제 수업 전에 한 번만)

1. [supabase.com](https://supabase.com) 에서 무료 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **SQL Editor** → `supabase/schema.sql` 파일 내용을 통째로 붙여넣고 **Run**.
3. 왼쪽 메뉴 **Settings → API** 에서 두 값을 복사합니다.
   - `Project URL`
   - `service_role` 키 (⚠️ 절대 공개하면 안 되는 값)
4. 이 폴더에 `.env.local` 파일을 만들고 아래처럼 채웁니다.

   ```
   SUPABASE_URL=https://여기에주소.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=여기에긴열쇠
   ```

5. 실행 중이던 서버를 끄고(`Ctrl + C`) 다시 `npm run dev` 를 칩니다.

선생님 화면 아래쪽의 노란 경고문이 사라지면 연결에 성공한 것입니다.
