# 그림 파일 넣는 곳

여기(`/public/images/`)에 아래 파일명 그대로 넣으면 앱에 자동으로 나타납니다.
**파일이 없어도 앱은 안 깨집니다.** 그림 자리에 회색 상자와 파일명이 대신 보입니다.

> 아래 표를 그대로 복사해서 그림 만드는 AI에게 주면 됩니다.

|---|---|---|---|
| `logo.png` | 앱 로고 (모든 화면 왼쪽 위) | 512 × 512 | 밝고 시원한 느낌. 나침반 + 네 갈래 길이 겹친 단순한 심볼. 배경 투명. 글자 없음. |

## 그림 만들 때 지켜야 할 것

- **특정 AI 회사 로고, 제품 이름, 요금제 표시가 절대 들어가면 안 됩니다.**
- 캐릭터 5종은 같은 그림체·같은 색감으로 통일해 주세요.
- 중학생 대상입니다. 밝고 시원하게, 유치하지 않게.
- 아이콘류는 배경 투명(PNG)이 좋습니다.
