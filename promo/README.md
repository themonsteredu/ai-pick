# AI 잘 부려먹기 홍보영상

- `ai-pick-promo.mp4`: 1920×1080, 30fps, 약 52초. 배경음악과 하단 한국어 자막이 들어 있습니다.
- 실제 앱 화면(첫 화면, 선생님 수업코드 만들기, 학생 입장, 진행 통제와 반 전체 막대그래프)을 녹화하고, 4단계 소개와 7가지 수업 활동 장면을 더해 자막과 함께 편집했습니다.
- 화면에 나오는 학생 닉네임과 응답은 모두 녹화용 가짜(더미) 데이터입니다. 실제 개인정보는 없습니다.
- `ai-pick-promo.srt`: 자막 파일입니다. 유튜브 등에 자막을 따로 올릴 때 씁니다.
- `source/`: 영상을 다시 만들 때 쓰는 녹화·편집 스크립트입니다. 앱 배포에는 포함되지 않습니다.
  - `go2.mjs`, `rec.mjs`: 앱을 켜 둔 상태(`npm run dev`)에서 화면을 녹화합니다.
  - `mask.py`: 선생님 화면의 `localhost` 주소 줄을 가립니다.
  - `compose.html`, `render.mjs`: 편집 화면을 프레임 단위로 렌더합니다. 실행 전에 앱의 `public/images` 그림 6장과 에스코어드림 글꼴(`fonts/`)을 같은 폴더에 넣어야 합니다.
  - `music.py`: 배경음악을 직접 합성합니다. 저작권 걱정이 없습니다.
